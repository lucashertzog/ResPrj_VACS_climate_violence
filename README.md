# ResPrj_VACS_climate_violence

Code supporting the paper: 

Hertzog, L., Makate, M., Chipanta, D., Banougnin, B., Mchenga, M., Pereira, G., Nyadanu, S.D., Dunne, J., Tallman, P.S., Collins, S., Alene, K.A., Rousseau-Gueutin, P., Mavisakalyan, A. and Hanigan, I.C. (2025) ‘Extreme drought and sexual violence against adolescent girls and young women: A multi-country population-based study’, PLOS Global Public Health. Edited by K. Jean, 5(6), p. e0004752. Available at: [https://doi.org/10.1371/journal.pgph.0004752](https://doi.org/10.1371/journal.pgph.0004752).

The drought exposure methods supporting the findings of this study are available through the Clean Air Research Data and Analysis Tools (CARDAT; [https://cardat.github.io/](https://cardat.github.io/)) platform on request.
